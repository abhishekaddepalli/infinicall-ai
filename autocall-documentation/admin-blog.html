Blog Management

Manage the blog using categories and tags to organize content effectively and improve content discovery.

Blogs Overview

The Blog Management module allows users to create, manage, and organize blog content efficiently using posts, categories, and tags. It provides a complete system to publish, edit, and control blog visibility while maintaining structured content organization.

Manage blog posts, assign categories and tags, upload thumbnails, and configure SEO settings to improve content reach and discoverability.

Dashboard

The Blogs dashboard displays all blog posts in a clean card-based layout. Each card shows key details such as title, publish date, author, tags, short description, and status (e.g., Pending or Published).

Quickly browse, search, and access blog posts, as well as click “Read More” to view full content. The Create New Post button allows quick access to add new blog content.

1. Create Blog
Before creating a blog post, add relevant tags and categories to ensure better organization and content management.

Create a new blog by clicking the Create New Post button. The blog form includes:

  • Title & Slug : Define the blog title and unique slug
  • Short Description : Add a brief summary of the blog
  • Knowledge Content : Use a rich text editor to write detailed content
  • Thumbnail Image : Upload a featured image for the blog post
  • Categories & Tags : Assign relevant categories and tags
  • Featured Option : Highlight important blog posts
  • Status Toggle : Enable or disable blog visibility
SEO & Meta Settings

SEO settings help optimize blog visibility:

  • Meta Title: Define search engine title
  • Meta Description: Add a description for search indexing

These settings improve search engine ranking and content discoverability.

2. Edit Blog

Click the edit option on a blog card to open the blog form. Update the title, content, categories, tags, thumbnail, or SEO settings, then click on the Update Blog button to apply the changes.

3. Delete Blog

Click the Delete option on a blog card to remove the post. A confirmation prompt appears before deletion to prevent accidental removal. Once deleted, the blog is permanently removed from the system.

  • Create and manage blog posts with title, content, thumbnail, and SEO settings.
  • Control blog status (publish/draft) for user visibility.
Categories Overview

The Categories section helps organize blog content into structured groups based on topics or themes. Categories make it easier to manage blog posts and improve navigation for users by grouping related content together.

Create, edit & delete categories and assign them while creating or updating blog posts. Using categories ensures better content organization and a cleaner blog structure.

Dashboard

The Categories Dashboard displays all created categories in a searchable and paginated table. Quickly view category name and perform actions like edit or delete.

1. Create Category

create a new category by clicking the Add Category button. Enter the category name, define a unique slug, and set the category status (active/inactive).

For example, categories like “Technology”, “AI Tools”, “Design”, or “Marketing” help group blog posts effectively.

2. Edit Category

Edit existing categories by clicking the edit icon. Update the category name, slug, or status as needed, then click the Update button to save changes instantly.

3. Delete Category

Delete a category by clicking the Delete icon. A confirmation prompt appears before removal to prevent accidental deletion. Once deleted, the category is removed and cannot be used for blog posts.

  • Organize blogs into structured topics or groups.
  • Each category includes name, slug, and status configuration.
  • Active categories are available for blog assignment.
Tags Overview

The Tags section is used to manage and organize blog content by assigning relevant keywords to each post. Tags help improve content discoverability, filtering, and search functionality within the blog system.

Create, edit & delete tags and assign them while creating or updating blog posts. Using tags effectively allows better categorization of topics and enhances user navigation across blog content.

Dashboard

The Tags Dashboard provides a centralized interface to manage all blog tags efficiently. It displays a list of created tags in a structured table with options to search, paginate, and perform quick actions like edit or delete.

Quickly view tag names, manage existing tags, and add new ones using the “Add Tag” button. This dashboard helps maintain organized tagging for blog content, improving content filtering and overall user experience.

1. Add Tags

Create new tags by clicking the Add Tag button. Enter a unique tag name to define a keyword or topic that can be assigned to blog posts. Once created, the tag becomes available for use in organizing and categorizing blog content.

For example, you can add tags like "aiart”, imagegeneration,” videogeneration,” to categorize and organize your blog posts effectively.

2. Edit Tag

Edit existing tags by clicking the edit icon next to any tag. Update the tag name as needed, then click the Update button to save changes and apply them instantly across all associated blog posts.

3. Delete Tag

Delete tags by clicking the Delete icon next to any tag. A confirmation prompt appears before removal to prevent accidental deletion. Once deleted, the tag is removed from the system and will no longer be available for blog posts.

  • Add keywords to blogs for flexible content labeling.
  • Improve search, filtering, and discoverability of blog posts.
  • Tags can be reused across multiple blogs.
